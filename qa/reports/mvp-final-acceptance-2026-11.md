# Финальный QA-отчёт о приёмке TXT-MVP FinDocs

**Вердикт:** **Ready for demo** *(блокеров в основном пользовательском маршруте не выявлено; зафиксированы минорные UI-дефекты и эксплуатационные риски локальной Ollama)*

## 1. Функциональная проверка через браузер (раздел 3 ТЗ)
- **Документы и загрузка (п. 3.1):**
  - Одиночная загрузка (`demo_reference.txt`) и пакетная загрузка (4 файла из `qa/test_data/`) отработали корректно; статусы обновляются через polling без перезагрузки до `Готов` (`ready`).
  - Граничные файлы: `empty.txt` (0 Б) и `too_big_over_10mb.txt` (>10 МБ) блокируются прямо в модальном окне с отключением кнопки «Загрузить»; после их удаления оставшаяся очередь отправляется. `bom_emoji.txt` успешно стал `ready`; `spaces_only.txt` и `broken_utf8.txt` перешли в статус `Ошибка` на сервере.
  - После обновления страницы библиотека сохраняется, поиск по кириллице работает, удаление с подтверждением удаляет документ.
- **Чат, область поиска и источники (п. 3.2):**
  - Подтверждена изоляция `scope`: при выбранном `demo_reference.txt` вопрос по `second_topic.txt` возвращает `insufficient_info` без подмешивания.
  - При снятии последней галочки остаётся пустой явный выбор, отправка блокируется; возврат к «Все документы» — явной кнопкой.
  - Панель источников открывается/закрывается, показывает `filename` и `quote` без HTML/JSON.
- **Отказоустойчивость (п. 3.3):**
  - При остановке backend UI отображает понятное сообщение (`HTTP 502`) с кнопкой «Повторить».
  - При остановке Ollama UI отображает «Сервис генерации ответа временно недоступен. Повторить запрос» и сохраняет текст введённого вопроса в поле ввода, позволяя продолжить после запуска Ollama без перезагрузки страницы.

## 4. Дефекты и риски
- **Блокирующие дефекты (Blocker):** **0**.
- **Необязательные дефекты (Minor):**
  1. **Не обновляется заголовок чата:** заголовок сессии слева сверху фиксируется по первому короткому/тестовому вводу и не обновляется при следующих вопросах.
  2. **Язык серверных ошибок в библиотеке:** при отклонении файла сервером (`spaces_only.txt`, `broken_utf8.txt`) в русском интерфейсе выводятся англоязычные сообщения (`TXT file is empty or contains only whitespace`, `TXT file must use UTF-8 encoding`).
  3. **Обрезанные вспомогательные цитаты:** при наличии правильной основной цитаты в источниках указываются рандомные и не несущие смысла никакого смысла цитаты. Например для `M08` источником вывелся обрывок «Независимую внешнюю». 
- **Эксплуатационные риски для демонстрации:**
  - Первый «холодный» запрос к Ollama после запуска может занимать до 5–13 секунд; при нехватке RAM/VRAM или простое Ollama возможен таймаут 90s.
  - При одновременном выборе «Все документы» среди нескольких файлов возможны редкие лишние фрагменты в 2–3-м источнике; для защиты рекомендуется выбирать только `demo_reference.txt`.
