### **Выявленные дефекты (для Ани)**
**Дефект 1:** Отсутствие блокировки кнопки UploadButton во время загрузки (Сценарий UI-04).   
•	Приоритет: P0  
•	Шаги: Инициировать загрузку файла.  
•	Ожидание: Кнопка получает атрибут disabled, предотвращая повторный клик.   
•	Факт: Кнопка остается активной.  
•	Лог QA-теста: Error: expect(element).toBeDisabled() / Received element is not disabled  

**Дефект 2:** SearchScopeSelector некорректно работает с предвыбранными ID (Сценарий UI-12).  
•	Приоритет: P0   
•	Шаги: Загрузить компонент с пропсом selectedIds={["1"]} и попытаться снять выбор.  
•	Ожидание: Документ должен отображаться в списке и позволять снять галочку (отправить пустой массив []).   
•	Факт: Текст документа (ready.txt) вообще не рендерится в DOM, снять выбор невозможно.   
•	Лог QA-теста: Unable to find an element with the text: ready.txt.
