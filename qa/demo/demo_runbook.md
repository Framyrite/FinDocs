# Сценарий демонстрации FinDocs (Runbook для защиты)

## 1. Запуск окружения (до выхода на защиту)
1. Запустить приложение **Ollama** и убедиться, что модель загружена (`ollama list` -> `qwen3.5:4b-q4_K_M`).
2. **Backend (терминал 1):**
   `cd backend && source venv/bin/activate && uvicorn app.main:app --host 127.0.0.1 --port 8000`
3. **Frontend (терминал 2):**
   `cd frontend && npm run dev`
4. Открыть браузер на `http://127.0.0.1:5173` (проверить, что в `backend/.env` стоит `FINDOCS_LLM_PROVIDER=ollama`, в `frontend/.env` — `VITE_USE_MOCK=false`).

## 2. Пошаговый маршрут показа (~2–3 минуты)
1. **Загрузка документа:** вкладка «Мои документы» -> «Загрузить документ» -> выбрать `qa/demo/demo_reference.txt` -> «Загрузить».
   - *Ожидаемый UI:* статус меняется с `Загружен` / `Обработка` на `Готов` (зелёная плашка).
2. **Вопрос №1 (основной + раскрытие источника):** перейти во вкладку «Чат», выбрать в области поиска `demo_reference.txt` и задать `M01`:
   `Кто и когда впервые выпустил облигации под названием «Климатические облигации» и на какой объём?`
   - *Ожидаемый UI:* ответ с фактами (ЕИБ, июль 2007, 600 млн евро) за ~4 с; нажать «Источники» и показать точную цитату из `demo_reference.txt`.
3. **Вопрос №2 (список компонентов):** задать `M02`:
   `Какие четыре ключевых компонента выделяют Принципы зелёных облигаций (GBP) от ICMA?`
   - *Ожидаемый UI:* структурированный ответ из 4 пунктов за ~5 с.
4. **Вопрос №3 (российский кейс, 1 точная цитата):** задать `M03`:
   `Кто и на какую сумму разместил первые зелёные облигации на российском рынке в декабре 2018 года?`
   - *Ожидаемый UI:* точный ответ про «Ресурсосбережение ХМАО» (1,1 млрд руб.) за ~3–4 с.
5. **Демонстрация честного отказа:** задать `M11`:
   `Какова точная ставка купона по зелёным облигациям компании «Ресурсосбережение ХМАО», размещённым в 2018 году?`
   - *Ожидаемый UI:* честный отказ без выдуманной ставки («В выбранных материалах не удалось найти достаточную информацию для ответа.») и без источников (~2 с).
6. **Изоляция поиска (опционально):** загрузить `qa/test_data/second_topic.txt`, выбрать в области поиска только его и повторить `M01` -> система откажет, не подмешивая `demo_reference.txt`.

## 3. Восстановление при сбоях на защите
- **Ошибка «Сервис генерации ответа временно недоступен» (503):** проверить, запущена ли Ollama, и нажать «Повторить запрос» — текст вопроса сохранится.
- **Ошибка HTTP 502 / обрыв backend:** перезапустить `uvicorn` в терминале 1 и нажать «Повторить».
- **Долгий первый ответ:** первый запрос прогревает веса `qwen3.5:4b-q4_K_M` в памяти (рекомендуется задать один пробный вопрос за 2 минуты до начала показа).
